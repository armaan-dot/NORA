# Foxglove for NORA

The full step-by-step guide (install, launch, connect Foxglove, English commands, scene JSON, topics) is in the main [README](../README.md#run-the-simulator-in-foxglove-ros-2--moveit).

- Layout to import: `foxglove/nora_foxglove_layout.json`
- ROS 2 launch: `ros2 launch nora_bringup sim_foxglove.launch.py`
- Foxglove connection: `ws://localhost:8765` (Foxglove WebSocket)
